# Frontend

Tauri, React, TypeScript, Vite, TailwindCSS, Zustand, React Router, React Query, Framer Motion, Lucide Icons, Monaco Editor, React Hook Form, and Zod frontend for Aether AI.

## Structure

- `components/` - Reusable UI and application components.
- `layouts/` - Desktop shell and route layouts.
- `pages/` - Route-level views.
- `hooks/` - React hooks.
- `contexts/` - React context providers.
- `services/` - API clients and external integration boundaries.
- `stores/` - Zustand state stores.
- `types/` - Frontend TypeScript types.
- `utils/` - Shared frontend utilities.
- `styles/` - Global styles and Tailwind entry points.
- `assets/` - Frontend assets.
- `animations/` - Motion presets.
- `features/` - Feature modules.
